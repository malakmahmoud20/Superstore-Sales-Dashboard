Excel Sales Dashboard

Project Overview

An interactive Excel dashboard designed to analyze sales and profit performance and present key business insights through data visualization.

Tools Used

- Microsoft Excel
- PivotTables and PivotCharts
- Slicers
- Data Analysis and Visualization

Key Analysis

- Sales and profit performance
- Sales by region
- Product category performance
- Interactive filtering
